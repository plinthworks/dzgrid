## What it does

The text comes from the columns, never guessed from the cell: `tooltip(value, row, context)` for a cell,
`headerTooltip` for a header. The keyboard does not wait: a tooltip shows as soon as the focus reaches its cell. The
pointer can move onto the tooltip without it going; Escape closes it. It stays inside the window and never covers what
it describes. The focused cell points to it with `aria-describedby` while it shows.

| Key | Default | What it does | Needs `tooltips()` |
|---|---|---|---|
| `delayMs` | `500` | How long the pointer rests before a tooltip shows, in ms | no |
| `hideDelayMs` | `150` | The grace after the pointer leaves, so it can cross onto the tooltip, in ms | no |
| `cells` | `true` | `false` silences every column's `tooltip` at once (a failed save's reason still shows) | no |
| `tone` | `'info'` | `info`, `neutral`, `success`, `warning` or `danger`; a column's `{ text, tone }` wins | no |
| `animation` | `'fade'` | `fade`, `scale`, `slide`, `pop`, `rise` or `none` (the presets of `@dzgrid/theme/tooltips.css`) | no |
| `reducedMotion` | `'none'` | Under reduced motion: nothing moves (`none`), or a short fade, opacity only (`fade`) | no |
| `html` | — | The cleaner, `safeHtml` from `@dzgrid/dom/tooltip`, that lets a column's `tooltip` return `{ html }` | no |
| `header` | `false` | The header's buttons (filter, column menu, floating filter toggle) show their name | yes |
| `placement` | `'auto'` | One of 12 placements (`top`, `bottom`, `start`, `end`, alone or with `-start` / `-end`), `left` / `right`, or `auto`: below, at the cell's start | yes |
| `flip` | `true` | `false`: never moved to the other side when it does not fit | yes |
| `animate` | — | Your own animation, `(el, phase, info)`, in place of the presets | yes |
| `shape` | — | The bubble drawn as your SVG path (a 100 × 100 box stretched over it) | yes |

The keys that need the [`tooltips()`](../../features/tooltips/) feature are told once as a problem without it
(`missing-feature`). A grid with [`motion`](../motion/) `false` opens and closes its tooltips at once. Placements,
animations, content and popovers, with live examples: [Tooltips and popovers](../../guides/tooltips-popovers/).

## Example

<CodeTabs>
<Fragment slot="ts">

```ts
import { createGrid } from '@dzgrid/dom';
import { EN } from '@dzgrid/dom/locales/en';

type Peak = { id: string; name: string; metres: number };

const grid = createGrid<Peak>(document.getElementById('peaks')!, {
  rows: [{ id: 'p1', name: 'Grey Tooth', metres: 3120 }],
  columns: [
    { id: 'name', header: 'Peak', tooltip: (_v, p) => `${p.name}, ${p.metres} m` },
    { id: 'metres', header: 'Height', type: 'number', headerTooltip: 'Height above sea level, in metres' },
  ],
  getRowId: (p) => p.id,
  messages: EN,
  tooltips: { delayMs: 200 },
});

grid.update({ tooltips: { delayMs: 800 } });
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component } from '@angular/core';
import { DzGrid, type DzgColumnOrGroup } from '@dzgrid/angular';
import { EN } from '@dzgrid/dom/locales/en';

type Peak = { id: string; name: string; metres: number };

@Component({
  selector: 'app-peaks',
  imports: [DzGrid],
  template: `<dz-grid [rows]="rows" [columns]="columns" [getRowId]="rowId" [messages]="messages" [tooltips]="{ delayMs: 200 }" />`,
})
export class Peaks {
  readonly rows: Peak[] = [{ id: 'p1', name: 'Grey Tooth', metres: 3120 }];
  readonly columns: DzgColumnOrGroup<Peak>[] = [
    { id: 'name', header: 'Peak', tooltip: (_v, p) => `${p.name}, ${p.metres} m` },
    { id: 'metres', header: 'Height', type: 'number', headerTooltip: 'Height above sea level, in metres' },
  ];
  readonly rowId = (p: Peak) => p.id;
  readonly messages = EN;
}
```

</Fragment>
<Fragment slot="element">

```ts
import '@dzgrid/element/define';
import type { DzGridElement } from '@dzgrid/element';
import { EN } from '@dzgrid/dom/locales/en';

type Peak = { id: string; name: string; metres: number };

const grid = document.querySelector<DzGridElement<Peak>>('dz-grid')!;
grid.columns = [
  { id: 'name', header: 'Peak', tooltip: (_v, p) => `${p.name}, ${p.metres} m` },
  { id: 'metres', header: 'Height', type: 'number', headerTooltip: 'Height above sea level, in metres' },
];
grid.getRowId = (p) => p.id;
grid.messages = EN;
grid.settings = { tooltips: { delayMs: 200 } };
grid.rows = [{ id: 'p1', name: 'Grey Tooth', metres: 3120 }];
```

</Fragment>
