For a page whose Content Security Policy forbids `<style>` elements it did not write.

<OptionFacts setting="injectStyles" />

## What it does

The grid needs a few layout rules to work at all: rows placed absolutely, sticky headers and pinned columns. By
default it writes them itself, once per document or shadow root, in a `<style>` element — and so does each feature
with layout of its own (filters, pages, the status bar…). A policy that allows them with a nonce: give it with
[`nonce`](../nonce/) and keep the default.

`false`: neither the grid nor its features write any `<style>`, your page loads the rules instead — except the date
panels, whose own sheets are written unless the page already holds them under the same `data-tzslot` ids. The base's are
`LAYOUT_CSS` from `@dzgrid/dom`, in the `dzgrid.layout` layer; every feature with layout of its own exports it from
its entry, named on its [page](../../features/) (`FILTERS_CSS`, `PAGINATION_CSS`, `STATUS_CSS`, `TREE_CSS`…). The look itself, `@dzgrid/theme`, is always
yours to load. The setting is read once: `update()` refuses a change.

## Example

<CodeTabs>
<Fragment slot="ts">

```ts
import { createGrid } from '@dzgrid/dom';
import { EN } from '@dzgrid/dom/locales/en';

type Log = { id: string; message: string; level: number };

createGrid<Log>(document.getElementById('logs')!, {
  rows: [{ id: 'l1', message: 'Pump started', level: 1 }],
  columns: [{ id: 'message', header: 'Message' }, { id: 'level', header: 'Level', type: 'number' }],
  getRowId: (l) => l.id,
  messages: EN,
  injectStyles: false,
});
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component } from '@angular/core';
import { DzGrid, type DzgColumnOrGroup } from '@dzgrid/angular';
import { EN } from '@dzgrid/dom/locales/en';

type Log = { id: string; message: string; level: number };

@Component({
  selector: 'app-logs',
  imports: [DzGrid],
  template: `<dz-grid [rows]="rows" [columns]="columns" [getRowId]="rowId" [messages]="messages" [injectStyles]="false" />`,
})
export class Logs {
  readonly rows: Log[] = [{ id: 'l1', message: 'Pump started', level: 1 }];
  readonly columns: DzgColumnOrGroup<Log>[] = [{ id: 'message', header: 'Message' }, { id: 'level', header: 'Level', type: 'number' }];
  readonly rowId = (l: Log) => l.id;
  readonly messages = EN;
}
```

</Fragment>
<Fragment slot="element">

```ts
import '@dzgrid/element/define';
import type { DzGridElement } from '@dzgrid/element';
import { EN } from '@dzgrid/dom/locales/en';

type Log = { id: string; message: string; level: number };

const grid = document.querySelector<DzGridElement<Log>>('dz-grid')!;
grid.columns = [{ id: 'message', header: 'Message' }, { id: 'level', header: 'Level', type: 'number' }];
grid.getRowId = (l) => l.id;
grid.messages = EN;
grid.settings = { injectStyles: false };
grid.rows = [{ id: 'l1', message: 'Pump started', level: 1 }];
```

</Fragment>
