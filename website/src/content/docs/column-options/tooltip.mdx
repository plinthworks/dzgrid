A tooltip on each cell, computed from the data.

<OptionFacts column="tooltip" />

## What it does

`tooltip(value, row, context)` returns the text, already translated, or null for none; `context` is the
grid's [`context`](../../settings/context/). The grid never guesses one from the cell's content. It shows when the
pointer rests on the cell (after the grid's [`tooltips`](../../settings/tooltips/) delay) and as soon as the keyboard
focus reaches it.

It may return more than words, a `TooltipSpec`:

| Key | What it does |
|---|---|
| `text` | The words (what a screen reader hears) |
| `tone` | `info` (the default), `neutral`, `success`, `warning` or `danger` |
| `placement` | Where it opens, one of 12 placements or `auto`; needs the [`tooltips()`](../../features/tooltips/) feature |
| `html` | HTML, shown cleaned only when the grid has the cleaner (`tooltips: { html: safeHtml }`); otherwise its `text`, or nothing |

[`tooltips`](../../settings/tooltips/)`.cells` false silences every column's tooltip at once. More in
[Tooltips and popovers](../../guides/tooltips-popovers/).

## Example

```ts
import { createGrid } from '@dzgrid/dom';
import { EN } from '@dzgrid/dom/locales/en';

type Bee = { id: string; hive: string; honey: number };

createGrid<Bee>(document.getElementById('hives')!, {
  rows: [{ id: 'h1', hive: 'Clover hill', honey: 12.5 }],
  columns: [
    { id: 'hive', header: 'Hive', tooltip: (v) => (v ? `Hive ${v}` : null) },
    { id: 'honey', header: 'Honey', type: 'number', tooltip: (v) => (Number(v) < 5 ? { text: 'Low: check the hive', tone: 'warning' } : null) },
  ],
  getRowId: (r) => r.id,
  messages: EN,
});
```
