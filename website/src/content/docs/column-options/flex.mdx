Makes the column stretch with the grid.

<OptionFacts column="flex" />

## What it does

The columns with a `flex` share the width the other columns leave, each in proportion to its number:
`flex: 2` takes twice what `flex: 1` takes. They follow the grid's width when the window is resized, and stay within
their [`minWidth`](../min-width/) and [`maxWidth`](../max-width/). With every column flexible, the columns always fill
the grid exactly; there is no separate « fit to width » switch.

Once the user resizes a flexible column, it keeps that width; the column menu's « Reset columns » makes it flexible
again. A value that is not a number of zero or more is refused with an `invalid-column` error; `0` is not flexible.

## Example

```ts
import { createGrid } from '@dzgrid/dom';
import { EN } from '@dzgrid/dom/locales/en';

type Tool = { id: string; name: string; shelf: number; notes: string };

createGrid<Tool>(document.getElementById('tools')!, {
  rows: [{ id: 't1', name: 'Hammer', shelf: 2, notes: 'Claw, 450 g' }],
  columns: [
    { id: 'name', header: 'Tool', flex: 1, minWidth: 120 },
    { id: 'shelf', header: 'Shelf', type: 'number', width: 90 },
    { id: 'notes', header: 'Notes', flex: 2, minWidth: 160 },
  ],
  getRowId: (r) => r.id,
  messages: EN,
});
```
