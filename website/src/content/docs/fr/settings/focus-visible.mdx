## Ce qu’il fait

Par défaut (`'always'`), la cellule active montre son anneau, un trait du fond à l’intérieur et une teinte, que le
focus y soit venu par les touches ou par un clic.

`'keyboard'` : après un appui de la souris, d’un stylet ou d’un doigt dans la grille, la cellule active — et un titre
de colonne ou un volet de détail actif — ne montre ni anneau, ni trait intérieur, ni teinte. Le focus reste où le clic
l’a mis (un lecteur d’écran l’a toujours) et la ligne garde sa teinte de ligne active. N’importe quelle touche dans la
grille ramène l’anneau tout de suite, et aussi le focus qui revient de l’extérieur de la grille (Tab, un raccourci, une
autre fenêtre). La grille note elle-même le dernier geste : cela marche pareil dans Firefox, où `:focus-visible` seul
ne suit pas les flèches après un clic. La poignée de recopie, les bords d’un bloc et un éditeur ouvert ne sont pas
l’anneau du focus : ils restent.

Ce n’est pas la clé `focusRing` du thème, qui est la couleur de l’anneau.

## Exemple

```ts
import { createGrid } from '@dzgrid/dom';
import { FR } from '@dzgrid/dom/locales/fr';

type Lamp = { id: string; street: string; watts: number };

const grid = createGrid<Lamp>(document.getElementById('lampadaires')!, {
  rows: [{ id: 'l1', street: 'Rue du Moulin', watts: 40 }],
  columns: [{ id: 'street', header: 'Rue' }, { id: 'watts', header: 'Watts', type: 'number' }],
  getRowId: (l) => l.id,
  messages: FR,
  focusVisible: 'keyboard',
});

grid.update({ focusVisible: 'always' });
```

En Angular, `<dz-grid focusVisible="keyboard">` ; dans le composant web, `<dz-grid focus-visible="keyboard">`.
