DzGrid affiche une infobulle simple sur une cellule ou un titre : des mots, un peu après que le pointeur s’arrête, tout
de suite pour le clavier, fermée par Échap. Les tons, placements, formes, animations, les infobulles partout dans votre
page et les bulles qui restent ouvertes vivent dans leur propre bibliothèque,
[DzTooltip](https://github.com/plinthworks/dztooltip), qu’une grille prend en une ligne.

## L’infobulle de la grille

Une colonne dit ce que disent les infobulles de ses cellules, déjà traduit ; la grille n’en devine jamais une d’après le
contenu :

| Option de colonne | Ce qu’elle affiche |
|---|---|
| [`tooltip`](../../column-options/tooltip/)`: (value, row, context) => text` | Vos mots pour chaque cellule, ou null pour aucune |
| `tooltip: true` | Le texte de la cellule tel qu’il est affiché |
| `tooltip: { when: 'truncated' }` | Le texte de la cellule, seulement quand il est coupé (des points de suspension) |
| `tooltip: { text, delayMs, content }` | Des mots fixes ou le texte affiché, le délai propre à la colonne, la réponse d’une cellule par-dessus |
| `tooltip: false` | Aucune, quoi que dise la grille |
| [`headerTooltip`](../../column-options/header-tooltip/) | Des mots sur le titre |

Le réglage [`tooltips`](../../settings/tooltips/) de la grille porte le délai (`delayMs`, 500 ms) et `cells` : `false`
fait taire toutes les colonnes, `'truncated'` donne à chaque colonne qui ne dit rien son texte coupé. Son apparence tient
en quelques variables (`--dzg-tooltip-bg`, `--dzg-tooltip-arrow-size`, … : [Thème](../theming-rtl/)) ; une partie peut
la dessiner ([`ui`](../../column-options/ui/)`.tooltip`).

## Des bulles plus riches : DzTooltip

[DzTooltip](https://github.com/plinthworks/dztooltip) dessine les infobulles de la grille quand vous ajoutez son pont —
des tons, douze placements, des formes toutes faites, des animations CSS (dont un morphing) ou les vôtres, le nom des
boutons des titres, et du HTML nettoyé :

```sh
npm install @dztooltip/dzgrid @dztooltip/theme
```

```text
import { dzTooltips } from '@dztooltip/dzgrid';
createGrid(host, { …, features: [dzTooltips({ tone: 'neutral', placement: 'top', animation: 'morph' })] });
```

Les options d’une colonne portent alors aussi leur apparence : `tooltip: { when: 'truncated', tone: 'warning', shape:
'pill' }`. Sans le pont, la grille affiche les mots et signale une fois qu’une apparence le demande (`missing-feature`).
Les infobulles sur n’importe quel élément de votre page et les bulles viennent de `@dztooltip/core` et, en Angular, de
`@dztooltip/angular` (`dzTooltip`, `dzPopover`).
