`@dzgrid/angular` enveloppe la grille DOM dans un composant autonome `<dz-grid>` aux entrées en signaux, pour
Angular 19 à 22, sans zone d’abord (zone.js marche aussi). Quand la même chose se fait sans Angular, les onglets la
montrent en [TypeScript](../typescript/) et avec le [composant web](../web-component/).

## Installer

```sh
npm install @dzgrid/core @dzgrid/dom @dzgrid/theme @dzgrid/angular
```

Dans `angular.json`, chargez le thème avant vos propres styles globaux :

```json
"styles": ["node_modules/@dzgrid/theme/dzgrid.css", "src/styles.css"]
```

L’hôte `<dz-grid>` est en `display: contents` (il n’a pas de boîte à lui) : dimensionnez son parent, en CSS
**global** — les styles émulés d’un composant n’atteignent pas le DOM de la grille.

```css
.grid-box { block-size: 480px; display: flex; flex-direction: column; }
.grid-box > dz-grid > .dzg { flex: 1; }
```

`columns`, `getRowId` et `messages` sont obligatoires (`messages` peut venir de `provideDzGrid`, plus bas). Typez le
tableau de colonnes `DzgColumnOrGroup<T>[]` : un littéral non typé cache les clés inconnues.

## Les entrées sont comparées par identité

Les entrées sont des signaux. Donnez un nouveau tableau ou objet pour changer quelque chose
(`rows.update((rs) => [...rs, x])`), jamais un objet modifié. Gardez les fonctions (`getRowId`, `rowClass`) et le
tableau `features` en champs de la classe : `features` est lu une fois, à la création de la grille.

<CodeTabs>
<Fragment slot="ts">

```ts
import { createGrid } from '@dzgrid/dom';
import { filters } from '@dzgrid/dom/filters-base';
import { EN } from '@dzgrid/dom/locales/en';
import { EN_FILTERS } from '@dzgrid/dom/locales/en-filters';

type Lamp = { id: number; model: string; watts: number };
let rows: Lamp[] = [{ id: 1, model: 'Moth 3', watts: 40 }];

const grid = createGrid<Lamp>(document.getElementById('lamps')!, {
  rows,
  columns: [{ id: 'model', header: 'Model' }, { id: 'watts', header: 'Watts', type: 'number' }],
  getRowId: (l) => l.id,
  messages: { ...EN, text: { ...EN.text, ...EN_FILTERS.text } },
  features: [filters()],
  selection: { mode: 'multi', checkbox: true },
  onEvent: (e) => {
    if (e.type === 'selectionChanged') console.log(e.count ?? 'some', 'selected');
  },
});

// A new array, never the old one changed.
rows = [...rows, { id: rows.length + 1, model: 'Heron 1', watts: 25 }];
grid.update({ rows });
```

```ts
import { Component, signal } from '@angular/core';
import { DzGrid, type DzgColumnOrGroup } from '@dzgrid/angular';
import type { Problem } from '@dzgrid/core';
import { filters } from '@dzgrid/dom/filters-base';
import { EN } from '@dzgrid/dom/locales/en';
import { EN_FILTERS } from '@dzgrid/dom/locales/en-filters';

type Lamp = { id: number; model: string; watts: number };

@Component({
  selector: 'app-lamps',
  imports: [DzGrid],
  template: `
    <button type="button" (click)="add()">Add a lamp</button>
    <div class="grid-box">
      <dz-grid [rows]="rows()" [columns]="columns" [getRowId]="rowId" [messages]="messages" [features]="features"
        [selection]="{ mode: 'multi', checkbox: true }" [(quick)]="quick"
        (selectionChanged)="count = $event.count" (problems)="onProblems($event)" />
    </div>
    <p>{{ count ?? 'some' }} selected</p>`,
})
export class Lamps {
  readonly rows = signal<Lamp[]>([{ id: 1, model: 'Moth 3', watts: 40 }]);
  readonly columns: DzgColumnOrGroup<Lamp>[] = [{ id: 'model', header: 'Model' }, { id: 'watts', header: 'Watts', type: 'number' }];
  readonly rowId = (l: Lamp) => l.id;
  readonly messages = { ...EN, text: { ...EN.text, ...EN_FILTERS.text } };
  readonly features = [filters()];
  quick = '';
  count: number | null = 0;
  add() { this.rows.update((rs) => [...rs, { id: rs.length + 1, model: 'Heron 1', watts: 25 }]); }
  onProblems(ps: readonly Problem[]) { for (const p of ps) console.warn('dzgrid', p.code, p.path, p.detail); }
}
```

Modèles à double sens : `[(quick)]`, `[(filter)]`, `[(selected)]`, `[(expanded)]`, `[(groupBy)]`. Non liés, c’est
la grille qui tient cet état.

## Valeurs par défaut de l’application

`provideDzGrid` donne à chaque `<dz-grid>` de l’application ses textes et ses réglages par défaut. Une liaison sur
la balise l’emporte sur une valeur par défaut.

```ts
import { ApplicationConfig } from '@angular/core';
import { provideDzGrid } from '@dzgrid/angular';
import { FR } from '@dzgrid/dom/locales/fr';

export const appConfig: ApplicationConfig = {
  providers: [provideDzGrid({ messages: FR, defaults: { locale: 'fr-FR', timeZone: 'Europe/Paris', density: 'compact' } })],
};
```

## Le contrôleur

`(gridReady)` remet un `DzgController` : commandes, focus, transactions, et l’api propre à chaque fonction par `use`.
Sans Angular, la grille elle-même offre la même chose : `grid.kernel` et `grid.api`.

<CodeTabs>
<Fragment slot="ts">

```ts
import { createGrid } from '@dzgrid/dom';
import { dataKey } from '@dzgrid/core';
import { EN } from '@dzgrid/dom/locales/en';

type Owl = { id: string; name: string; age: number };

const grid = createGrid<Owl>(document.getElementById('owls')!, {
  rows: [{ id: 'o1', name: 'Pip', age: 3 }, { id: 'o2', name: 'Bramble', age: 9 }],
  columns: [{ id: 'name', header: 'Owl' }, { id: 'age', header: 'Age', type: 'number' }],
  getRowId: (o) => o.id,
  messages: EN,
  selection: { mode: 'multi' },
});

grid.kernel.dispatch({ type: 'sort.set', sort: [{ column: 'age', dir: 'desc' }] }, 'api');
const key = dataKey('o2');
if (key) {
  grid.api.ensureVisible(key, 'name');
  grid.kernel.dispatch({ type: 'selection.only', row: key }, 'api');
}
grid.kernel.rows.applyTransaction({ patch: [{ id: 'o1', set: { age: 4 } }] });
```

```ts
import { Component } from '@angular/core';
import { DzGrid, DzgController, selectedIds, type DzgColumnOrGroup } from '@dzgrid/angular';
import { dataKey } from '@dzgrid/core';
import { EN } from '@dzgrid/dom/locales/en';

type Owl = { id: string; name: string; age: number };

@Component({
  selector: 'app-owls',
  imports: [DzGrid],
  template: `<dz-grid [rows]="rows" [columns]="columns" [getRowId]="rowId" [messages]="messages"
    [selection]="{ mode: 'multi' }" (gridReady)="ctrl = $event" />
    <button type="button" (click)="oldestFirst()">Oldest first</button>`,
})
export class Owls {
  readonly rows: Owl[] = [{ id: 'o1', name: 'Pip', age: 3 }, { id: 'o2', name: 'Bramble', age: 9 }];
  readonly columns: DzgColumnOrGroup<Owl>[] = [{ id: 'name', header: 'Owl' }, { id: 'age', header: 'Age', type: 'number' }];
  readonly rowId = (o: Owl) => o.id;
  readonly messages = EN;
  ctrl: DzgController<Owl> | null = null;

  oldestFirst() {
    this.ctrl?.dispatch({ type: 'sort.set', sort: [{ column: 'age', dir: 'desc' }] });
    const key = dataKey('o2');
    if (key) {
      this.ctrl?.ensureVisible(key, 'name');
      this.ctrl?.dispatch({ type: 'selection.only', row: key });
    }
    this.ctrl?.applyTransaction({ patch: [{ id: 'o1', set: { age: 4 } }] });
    const chosen = this.ctrl && selectedIds(this.ctrl);   // { mode, ids, query } — ids, ready for a server
    console.log(chosen);
  }
}
```

## Des parties en composants

Une cellule (ou un en-tête, une infobulle, un éditeur, un panneau de détail…) peut être un composant Angular avec
une entrée signal nommée `cell`. Les instances sont réutilisées d’une ligne à l’autre : tirez tout de `cell()`.

```ts
import { ChangeDetectionStrategy, Component, input } from '@angular/core';
import { DzGrid, type DzgColumnOrGroup, type DzgPartContext } from '@dzgrid/angular';
import { EN } from '@dzgrid/dom/locales/en';

type Robot = { id: string; name: string; state: 'awake' | 'asleep' };

@Component({
  selector: 'app-robot-state',
  changeDetection: ChangeDetectionStrategy.OnPush,
  template: `<span>{{ cell().text }}</span>
    <button type="button" (click)="cell().emit('wake', robot().id)">Wake</button>`,
})
export class RobotState {
  readonly cell = input.required<DzgPartContext<'cell'>>();
  robot(): Robot { return this.cell().row as Robot; }
}

@Component({
  selector: 'app-robots',
  imports: [DzGrid],
  template: `<dz-grid [rows]="rows" [columns]="columns" [getRowId]="rowId" [messages]="messages"
    (cellAction)="last = $event.name + ' ' + $event.detail" />`,
})
export class Robots {
  readonly rows: Robot[] = [{ id: 'r1', name: 'Tock', state: 'asleep' }];
  readonly columns: DzgColumnOrGroup<Robot>[] = [{ id: 'name', header: 'Robot' }, { id: 'state', header: 'State', ui: { cell: RobotState } }];
  readonly rowId = (r: Robot) => r.id;
  readonly messages = EN;
  last = '';
}
```

Autres façons de donner une partie : `componentPart(slot, Component)` dans `[parts]` ou `provideDzGrid({ parts })` ;
un `<ng-template dzgPart="name" [slot]="'header'" let-c>` dans `<dz-grid>` (importez `DzgPart`) ; ou une partie DOM
simple faite avec `definePart` de `@dzgrid/dom`.

## Pièges

<Aside type="caution">
- Pas de `messages` : la page reste vide et la console dit `dz-grid: messages are required`.
- Une fonction dont les textes ne sont pas fusionnés dans `messages` lève une erreur à la création, en nommant les
  clés manquantes.
- Une sortie qui n’existe pas (`(selectionChange)`) ne se déclenche jamais et ne dit rien : seules les sorties que
  le composant liste existent ; `(gridEvent)` porte chaque événement.
- `features` écrit dans le gabarit (`[features]="[filters()]"`) crée un nouveau tableau à chaque vérification :
  gardez-le en champ.
</Aside>
