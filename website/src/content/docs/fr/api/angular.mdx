Chaque nom public de `@dzgrid/angular`, entrée par entrée, avec sa déclaration telle que les types publiés la donnent. Fait depuis [`api/dzgrid-angular.api.txt`](https://github.com/plinthworks/dzgrid/blob/main/api/dzgrid-angular.api.txt), la surface qu’un test empêche de rétrécir d’une version à l’autre ; les guides et les pages d’options disent ce que fait chaque nom. Les déclarations sont du code : elles restent en anglais.
