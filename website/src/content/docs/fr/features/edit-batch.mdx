Les modifications gardées dans la grille jusqu’à ce que vous les enregistriez ensemble, données dans `features` à côté de `edit()`.

<FeatureFacts name="editBatch" />

## Ce qu’il fait

Avec `editBatch()` dans `features`, chaque geste — un champ gardé, un oui / non basculé, Suppr, une annulation, une
ligne gardée avec [`rowEditor`](../row-editor/) — est vérifié comme d’habitude et
montré aussitôt, mais rien ne part : la cellule est **en attente**. Elle porte un triangle dans son coin haut côté début
et une teinte légère (`--dzg-pending-mark`, `--dzg-pending-bg`, dans `@dzgrid/theme/forms.css`) et les lecteurs d’écran
entendent « Non enregistré ». Une cellule changée deux fois est une seule modification ; revenue à sa valeur enregistrée,
elle n’est plus en attente.

Un collage (ou une coupe) et un remplissage (la poignée, Ctrl+D / Ctrl+R) sont **enregistrés aussitôt** par défaut,
comme sans le lot : une requête chacun (`origin: 'paste'`, `'cut'`, `'fill'`), rien en attente, pas de « Tout
enregistrer » à montrer. Sur une cellule en attente, la valeur enregistrée l’emporte : la requête la porte, la
modification en attente de la cellule est abandonnée et les lecteurs d’écran entendent « 1 modification abandonnée ».
Les options ci-dessous les gardent en attente à la place.

`batch.api(grid)` donne :

- `pending()` : la liste des `{ key, column, value, previous, row }`, la nouvelle valeur et celle enregistrée qu’elle
  remplace.
- `count` : combien de cellules attendent.
- `saveAll()` : chaque modification vérifiée à nouveau (les règles de chaque colonne, puis `validateRow` s’il est donné)
  et envoyée **en une seule requête** à votre `save` (`origin: 'batch'`). Un refus local n’envoie rien. Elle se résout en
  `{ sent, refused }` une fois votre réponse reçue ; votre réponse refuse des cellules comme toute sauvegarde
  (`cells: [{ key, column, reason }]`), chacune revenue à sa valeur enregistrée avec sa raison.
- `discardAll()`, `discard(key, column?)` : les modifications abandonnées, les valeurs enregistrées de retour.

Annuler et rétablir marchent sur les modifications en attente. Une modification est gardée par clé de ligne : triée,
filtrée, sur une autre page d’une source serveur, elle revient quand sa ligne revient. La grille dit `pendingChange`
(`{ count }`) chaque fois que le compte bouge — Angular `(pendingChange)` et `ctrl.batch()`, l’élément
`dzg-pending-change` — pour que votre page prévienne avant de partir ; la grille n’ouvre jamais de boîte de dialogue.

## Options

- `validateRow` : une règle sur chaque ligne en attente, `(values, row, context) => { column, code } | liste | null`,
  vérifiée avant que `saveAll()` envoie ; son code est dit par votre texte `validation.<code>`.
- `paste: 'save' | 'pending'` (défaut `'save'`) : un collage ou une coupe enregistré aussitôt, ou gardé en attente (un
  geste, une annulation).
- `fill: 'save' | 'pending'` (défaut `'save'`) : de même pour un remplissage.

## Exemple

```ts
import { createGrid } from '@dzgrid/dom';
import { edit } from '@dzgrid/dom/edit';
import { editors } from '@dzgrid/dom/editors-base';
import { editBatch } from '@dzgrid/dom/edit-batch';
import { EN } from '@dzgrid/dom/locales/en';
import { EN_EDIT } from '@dzgrid/dom/locales/en-edit';
import { EN_EDITORS } from '@dzgrid/dom/locales/en-editors';
import { EN_FORMS } from '@dzgrid/dom/locales/en-forms';
import '@dzgrid/theme/edit.css';
import '@dzgrid/theme/forms.css';

type Item = { id: string; name: string; stock: number };

const batch = editBatch<Item>();
const grid = createGrid<Item>(document.getElementById('stock')!, {
  rows: [{ id: 'a1', name: 'Lamp', stock: 4 }, { id: 'a2', name: 'Desk', stock: 0 }],
  columns: [
    { id: 'name', header: 'Name', editable: true },
    { id: 'stock', header: 'Stock', type: 'number', editable: true, edit: { min: 0 } },
  ],
  getRowId: (r) => r.id,
  messages: { ...EN, text: { ...EN.text, ...EN_EDIT.text, ...EN_EDITORS.text, ...EN_FORMS.text } },
  // One request for every change, when the user presses « Save all ».
  features: [edit<Item>({ save: (req) => fetch('/api/items', { method: 'PATCH', body: JSON.stringify(req.changes) }) }), editors(), batch],
});

document.getElementById('save-all')!.addEventListener('click', async () => {
  const { sent, refused } = await batch.api(grid)!.saveAll();
  console.log(`${sent} sent, ${refused.length} refused`);
});
document.getElementById('cancel-all')!.addEventListener('click', () => batch.api(grid)!.discardAll());
// The application warns before leaving; the grid never opens a dialog.
window.addEventListener('beforeunload', (e) => {
  if (batch.api(grid)?.count) e.preventDefault();
});
```
