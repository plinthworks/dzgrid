La place du texte des cellules, et du titre par défaut.

<OptionFacts column="align" />

## Ce qu’il fait

`'start'`, `'center'` ou `'end'`, des côtés logiques : de droite à gauche, `'end'` est la gauche. Une
colonne `number` se place à la fin pour aligner ses chiffres ; tout autre type au début. Le titre de l’en-tête suit,
sauf si [`headerAlign`](../header-align/) dit autre chose.

## Exemple

```ts
import { createGrid } from '@dzgrid/dom';
import { FR } from '@dzgrid/dom/locales/fr';

type Tool = { id: string; name: string; shelf: number; notes: string };

createGrid<Tool>(document.getElementById('outils')!, {
  rows: [{ id: 't1', name: 'Marteau', shelf: 2, notes: 'Arrache-clou, 450 g' }],
  columns: [
    { id: 'name', header: 'Outil' },
    { id: 'shelf', header: 'Étagère', type: 'number', align: 'center' },
  ],
  getRowId: (r) => r.id,
  messages: FR,
});
```
