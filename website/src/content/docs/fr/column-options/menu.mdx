Retire le menu de colonne à une seule colonne.

<OptionFacts column="menu" />

## Ce qu’il fait

Avec la fonction `columnMenu()`, chaque titre a un bouton ⋮, un menu au clic droit et les touches
Alt+Flèche bas et Maj+F10 pour l’ouvrir. `menu: false` retire les trois du titre de cette colonne ; les touches sont
alors laissées à la page. Le tri par un clic sur le titre ne change pas ([`sortable`](../sortable/) en décide).

## Exemple

```ts
import { createGrid, type GridMessages } from '@dzgrid/dom';
import { columnMenu } from '@dzgrid/dom/column-menu';
import { FR_COLUMN_MENU } from '@dzgrid/dom/locales/fr-column-menu';
import { FR } from '@dzgrid/dom/locales/fr';

type Tool = { id: string; name: string; shelf: number; notes: string };

const messages: GridMessages = { ...FR, text: { ...FR.text, ...FR_COLUMN_MENU.text } };

createGrid<Tool>(document.getElementById('outils')!, {
  rows: [{ id: 't1', name: 'Marteau', shelf: 2, notes: 'Arrache-clou, 450 g' }],
  columns: [
    { id: 'name', header: 'Outil' },
    { id: 'shelf', header: 'Étagère', type: 'number', menu: false },
  ],
  getRowId: (r) => r.id,
  messages,
  features: [columnMenu()],
});
```
