Si les lignes peuvent être triées par cette colonne.

<OptionFacts column="sortable" />

## Ce qu’il fait

Un clic sur le titre d’une colonne triable (ou Entrée dessus) trie par elle. `sortable: false` en fait un
titre simple : pas de clic, pas de flèche de tri, pas de « Trier » dans le menu de colonne. Un tri que votre code
demande sur elle (`sort.set`, un état enregistré) est refusé avec une erreur `invalid-sort`.

## Exemple

```ts
import { createGrid } from '@dzgrid/dom';
import { FR } from '@dzgrid/dom/locales/fr';

type Tool = { id: string; name: string; shelf: number; notes: string };

createGrid<Tool>(document.getElementById('outils')!, {
  rows: [{ id: 't1', name: 'Marteau', shelf: 2, notes: 'Arrache-clou, 450 g' }],
  columns: [
    { id: 'name', header: 'Outil' },
    { id: 'notes', header: 'Notes', sortable: false },
  ],
  getRowId: (r) => r.id,
  messages: FR,
});
```
