Garde une colonne hors de la liste où l’utilisateur affiche, masque et ordonne les colonnes.

<OptionFacts column="chooser" />

## Ce qu’il fait

Le sélecteur de colonnes (`columnsChooser()` de `@dzgrid/dom/columns-panel`) liste chaque colonne avec une
case pour l’afficher ou la masquer. `chooser: false` laisse cette colonne hors de la liste — une colonne technique,
une colonne que votre application affiche à sa façon. Le menu de colonne peut toujours la masquer, sauf si
[`hideable`](../hideable/) vaut `false`.

## Exemple

```ts
import { createGrid, type GridMessages } from '@dzgrid/dom';
import { columnsChooser } from '@dzgrid/dom/columns-panel';
import { FR_COLUMNS } from '@dzgrid/dom/locales/fr-columns';
import { FR } from '@dzgrid/dom/locales/fr';

type Tool = { id: string; name: string; shelf: number; notes: string };

const messages: GridMessages = { ...FR, text: { ...FR.text, ...FR_COLUMNS.text } };

createGrid<Tool>(document.getElementById('outils')!, {
  rows: [{ id: 't1', name: 'Marteau', shelf: 2, notes: 'Arrache-clou, 450 g' }],
  columns: [
    { id: 'name', header: 'Outil' },
    { id: 'shelf', header: 'Étagère', type: 'number', chooser: false },
  ],
  getRowId: (r) => r.id,
  messages,
  features: [columnsChooser()],
});
```
