Une infobulle sur chaque cellule, calculée à partir des données.

<OptionFacts column="tooltip" />

## Ce qu’il fait

`tooltip(value, row, context)` renvoie le texte, déjà traduit, ou null pour aucun ; `context` est le
[`context`](../../settings/context/) de la grille. La grille n’en devine jamais un d’après le contenu de la cellule.
Elle s’affiche quand le pointeur reste sur la cellule (après le délai des [`tooltips`](../../settings/tooltips/) de
la grille) et dès que le focus du clavier l’atteint.

**En une ligne** (1.12.0) : `tooltip: true` affiche le texte de la cellule tel qu’il est affiché ;
`tooltip: { when: 'truncated' }` seulement quand ce texte est coupé ; `tooltip: false` aucune, même avec
`tooltips: { cells: 'truncated' }` sur la grille. Des options `{ text, when, delayMs, content }` : sans `text`, le
texte affiché de la cellule ; `delayMs`, le délai de survol propre à la colonne ; `content(value, row, context)`, la
réponse de la cellule posée sur ces options (des mots, des options, ou null pour aucune). Une fonction peut aussi
renvoyer des options au lieu de mots.

Les options peuvent porter une apparence — `tone`, `placement`, `animation`, `shape`, `style`, `maxWidth` ou `html` —
que l’infobulle de la grille ne dessine pas : le pont de [DzTooltip](../../guides/tooltips-popovers/) la dessine,
`features: [dzTooltips({ … })]`. Sans lui, la grille affiche les mots et le signale une fois (`missing-feature`).

## Exemple

```ts
import { createGrid } from '@dzgrid/dom';
import { FR } from '@dzgrid/dom/locales/fr';

type Bee = { id: string; hive: string; honey: number };

createGrid<Bee>(document.getElementById('ruches')!, {
  rows: [{ id: 'h1', hive: 'Colline aux trèfles', honey: 12.5 }],
  columns: [
    { id: 'hive', header: 'Ruche', tooltip: (v) => (v ? `Ruche ${v}` : null) },
    { id: 'honey', header: 'Miel', type: 'number', tooltip: { when: 'truncated' } },
  ],
  getRowId: (r) => r.id,
  messages: FR,
});
```
