Une infobulle sur le titre, pour en dire plus que le titre ne peut.

<OptionFacts column="headerTooltip" />

## Ce qu’il fait

Elle s’affiche quand le pointeur reste sur le titre (après le délai des
[`tooltips`](../../settings/tooltips/) de la grille) et dès que le focus du clavier l’atteint. Donnez-la déjà
traduite. Pour la dessiner vous-même, nommez une partie dans [`ui`](../ui/)`.tooltip`.

## Exemple

```ts
import { createGrid } from '@dzgrid/dom';
import { FR } from '@dzgrid/dom/locales/fr';

type Bee = { id: string; hive: string; honey: number };

createGrid<Bee>(document.getElementById('ruches')!, {
  rows: [{ id: 'h1', hive: 'Colline aux trèfles', honey: 12.5 }],
  columns: [
    { id: 'hive', header: 'Ruche' },
    { id: 'honey', header: 'Miel', type: 'number', headerTooltip: 'Kilos cette saison' },
  ],
  getRowId: (r) => r.id,
  messages: FR,
});
```
