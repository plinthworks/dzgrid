Une colonne qui existe mais n’est pas affichée au démarrage de la grille.

<OptionFacts column="hidden" />

## Ce qu’il fait

Une colonne masquée reste une colonne : elle garde son tri et son filtre, et elle peut être de nouveau
affichée. L’utilisateur l’affiche depuis le sélecteur de colonnes ; votre code depuis l’état de la grille
ou en redonnant les colonnes. Le choix de l’utilisateur l’emporte sur `hidden` et fait partie de l’état enregistré ;
le « Réinitialiser les colonnes » du menu de colonne redonne celui de la définition.

Par défaut, les colonnes masquées sont laissées hors des fichiers et de l’impression, qui montrent les colonnes
visibles.

## Exemple

```ts
import { createGrid } from '@dzgrid/dom';
import { FR } from '@dzgrid/dom/locales/fr';

type Tool = { id: string; name: string; shelf: number; notes: string };

createGrid<Tool>(document.getElementById('outils')!, {
  rows: [{ id: 't1', name: 'Marteau', shelf: 2, notes: 'Arrache-clou, 450 g' }],
  columns: [
    { id: 'name', header: 'Outil' },
    { id: 'shelf', header: 'Étagère', type: 'number', hidden: true },
  ],
  getRowId: (r) => r.id,
  messages: FR,
});
```
