La place du titre de l’en-tête, par-dessus l’`align` de la colonne.

<OptionFacts column="headerAlign" />

## Ce qu’il fait

`'start'`, `'center'` ou `'end'`, des côtés logiques. Sans lui, le titre suit [`align`](../align/) : le
titre d’une colonne `number` se place à la fin, comme ses cellules. Donnez `headerAlign: 'start'` pour garder tous les
titres au début pendant que les nombres restent à la fin.

## Exemple

```ts
import { createGrid } from '@dzgrid/dom';
import { FR } from '@dzgrid/dom/locales/fr';

type Tool = { id: string; name: string; shelf: number; notes: string };

createGrid<Tool>(document.getElementById('outils')!, {
  rows: [{ id: 't1', name: 'Marteau', shelf: 2, notes: 'Arrache-clou, 450 g' }],
  columns: [
    { id: 'name', header: 'Outil' },
    { id: 'shelf', header: 'Étagère', type: 'number', headerAlign: 'start' },
  ],
  getRowId: (r) => r.id,
  messages: FR,
});
```
