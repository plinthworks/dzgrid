On a narrow screen, takes the columns that do not fit out of the rows and shows them under each row.

<FeatureFacts name="responsive" />

## What it does

When the columns do not fit the view, `responsive()` takes centre columns out of the rows instead of making the grid
scroll sideways. A chevron on each row's first cell then opens « Title: value » lines under the row, one per column
taken out. The column with the highest [`collapsePriority`](../../column-options/collapse-priority/) goes first (a
column without one counts 1); among equals, the last on screen. The first column, pinned columns and a priority of 0
never go. A flexible column counts its `minWidth`. It follows every resize.

On a row's first cell, Enter or Space opens and closes its lines. The quick search, the filters, the files and print
still see every column, and nothing is saved in the grid state.

The lines are a detail rows panel, so the `-detail` texts are needed. It cannot be combined with a tree, row grouping,
header groups, merged cells ([`spans()`](../spans/)) or your own [`detail()`](../detail/): the grid tells
`unsupported-combination`. A column with
`collapsePriority` on a grid without this feature tells a `missing-feature` warning.

## Options

- `priority`: a collapse priority by column id, over the columns' own `collapsePriority`. The highest collapses first;
  0 never.

## Example

```ts
import { createGrid, type GridMessages } from '@dzgrid/dom';
import { responsive } from '@dzgrid/dom/responsive';
import { EN } from '@dzgrid/dom/locales/en';
import { EN_DETAIL } from '@dzgrid/dom/locales/en-detail';

type Hive = { id: string; name: string; apiary: string; frames: number; queen: string; checked: string };
const messages: GridMessages = { ...EN, text: { ...EN.text, ...EN_DETAIL.text } };

createGrid<Hive>(document.getElementById('hives')!, {
  rows: [{ id: 'h1', name: 'Clover', apiary: 'Hill', frames: 9, queen: 'Marked blue', checked: '2026-05-02' }],
  columns: [
    { id: 'name', header: 'Hive', width: 160 },
    { id: 'apiary', header: 'Apiary', width: 140, collapsePriority: 2 },
    { id: 'frames', header: 'Frames', type: 'number', width: 100, collapsePriority: 0 },
    { id: 'queen', header: 'Queen', width: 180 },
    { id: 'checked', header: 'Checked', type: 'day', width: 140 },
  ],
  getRowId: (h) => h.id,
  messages,
  features: [responsive({ priority: { queen: 3 } })],
});
```
