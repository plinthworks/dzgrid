Binds a search field of your page to the grid: every word typed must be found in the row.

<FeatureFacts name="quickSearch" />

## What it does

`quickSearch()` draws no field. You write your own `<input>` (its label, its place, its style) and hand it to
`bind(input)`. Every word typed must appear somewhere in the row, in any visible column, in any order. Case, accents and
Arabic short vowels are ignored. Number and date columns are searched only for a word that holds a digit; hidden
columns are never searched; a yes/no column is searched by its word (« Yes », « No ») in the grid's language.

The rows narrow after a short pause: 150 ms in the browser, 300 ms when a server searches, or the `debounceMs` given to
`bind(input, { debounceMs })` (a value that is not a number of 0 or more gives the default). Enter applies at once,
Escape empties the field, ↓ goes into the grid. Once the rows settle, the grid says how many it found. The words found
are tinted inside the cells the grid draws (`@dzgrid/theme/search.css`); a cell drawn by your own part is left alone.

`bind` can be called for several fields; it returns a function that unbinds. The search and the column filters both
apply: a row must pass both. The grid draws no text of its own for the search, so the feature needs no texts bundle.

## Options

- `highlight`: tints the words found inside the cells. On by default; `false` leaves the cells alone. Read when the
  grid is made.

## Example

```ts
import { createGrid } from '@dzgrid/dom';
import { quickSearch } from '@dzgrid/dom/search';
import { EN } from '@dzgrid/dom/locales/en';
import '@dzgrid/theme/search.css';

type Book = { id: string; title: string; pages: number };

const search = quickSearch({ highlight: true });
createGrid<Book>(document.getElementById('books')!, {
  rows: [{ id: 'b1', title: 'The Salt Road', pages: 312 }],
  columns: [
    { id: 'title', header: 'Title' },
    { id: 'pages', header: 'Pages', type: 'number' },
  ],
  getRowId: (b) => b.id,
  messages: EN,
  features: [search],
});

const unbind = search.bind(document.querySelector<HTMLInputElement>('#book-search')!, { debounceMs: 200 });
// Later: unbind();
```
