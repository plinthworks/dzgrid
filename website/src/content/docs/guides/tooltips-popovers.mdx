DzGrid shows a plain tooltip on a cell or a header: words, a little after the pointer rests, at once for the keyboard,
closed by Escape. Tones, placements, shapes, animations, tooltips anywhere in your page and popovers that stay open
live in their own library, [DzTooltip](https://github.com/plinthworks/dztooltip), which a grid takes in one line.

## The grid's tooltip

A column says what its cells' tooltips say, already translated; the grid never guesses one from the content:

| Column option | What it shows |
|---|---|
| [`tooltip`](../../column-options/tooltip/)`: (value, row, context) => text` | Your words for each cell, or null for none |
| `tooltip: true` | The cell's text as displayed |
| `tooltip: { when: 'truncated' }` | The cell's text, only while it is cut (an ellipsis) |
| `tooltip: { text, delayMs, content }` | Fixed words or the displayed text, the column's own delay, a cell's own answer over them |
| `tooltip: false` | None, whatever the grid says |
| [`headerTooltip`](../../column-options/header-tooltip/) | Words over the header |

The grid's [`tooltips`](../../settings/tooltips/) setting holds the delay (`delayMs`, 500 ms) and `cells`: `false`
silences every column, `'truncated'` gives every column that says nothing its cut text. Its look is a few variables
(`--dzg-tooltip-bg`, `--dzg-tooltip-arrow-size`, …: [Theming](../theming-rtl/)); a part can draw it
([`ui`](../../column-options/ui/)`.tooltip`).

## Richer bubbles: DzTooltip

[DzTooltip](https://github.com/plinthworks/dztooltip) draws the grid's tooltips when you add its bridge — tones,
twelve placements, ready-made shapes, CSS animations (a morph among them) or your own, the header buttons' names, and
cleaned HTML:

```sh
npm install @dztooltip/dzgrid @dztooltip/theme
```

```text
import { dzTooltips } from '@dztooltip/dzgrid';
createGrid(host, { …, features: [dzTooltips({ tone: 'neutral', placement: 'top', animation: 'morph' })] });
```

A column's options then carry their look too: `tooltip: { when: 'truncated', tone: 'warning', shape: 'pill' }`.
Without the bridge, the grid shows the words and tells once that a look needs it (`missing-feature`). Tooltips on any
element of your page and popovers come from `@dztooltip/core` and, in Angular, `@dztooltip/angular` (`dzTooltip`,
`dzPopover`).
