# Behaviour sheets

One sheet per behaviour DzGrid borrows from another grid, **in our own
words**, written before the code (see `CLEANROOM.md`):

- **What the user does** — the gesture, the key, the click.
- **What they observe** — the result on screen, as a person describes it.
- **What DzGrid does** — the same, or deliberately different (right-to-left,
  keyboard, accessibility, time zones), and why.
- **Tests** — the specs and conformance cases that point back here.

Sources allowed: the public documentation and live demos of a grid, public
issue reports (for the symptom only), and the standards. Never source code.
